# 🧮 CalcSphere - Advanced Modern Calculator

An elegant, responsive, and feature-rich Scientific Calculator web application built with **HTML5, CSS3 (Glassmorphism & CSS Variables), and Vanilla JavaScript**.

![CalcSphere Preview](preview.png) *(Optional preview screenshot)*

---

## ✨ Features

- **🎨 Modern Glassmorphism UI**:
  - Blur backdrop filters, neon gradients, and fluid button interactions.
  - Custom typography with *Plus Jakarta Sans* & *JetBrains Mono*.
- **🌗 Theme Toggle**:
  - Seamlessly switch between Dark Mode and Light Mode.
  - Automatically remembers your theme preference (`localStorage`).
- **🔬 Full Scientific Math Support**:
  - Trigonometry: `sin`, `cos`, `tan`, `sin⁻¹`, `acos`, `atan`
  - Mode Switch: Degrees (`DEG`) & Radians (`RAD`)
  - Logarithms & Exponents: `ln`, `log₁₀`, `e`, `xʸ`, `10ˣ`
  - Powers & Roots: `x²`, `x³`, `√x`, `∛x`
  - Factorials (`x!`), Absolute value (`|x|`), Random generator (`RND`), and Constants (`π`, `e`)
- **🧠 Memory Registers**:
  - `MC` (Clear Memory)
  - `MR` (Recall Memory)
  - `M+` (Add to Memory)
  - `M-` (Subtract from Memory)
  - `MS` (Store to Memory)
  - Visual badge indicator when memory contains data.
- **🕒 Calculation History Drawer**:
  - Tracks and stores up to 30 recent calculations with timestamps.
  - Click on any historical calculation to instantly recall the result to the display.
  - Clear history with a single tap.
- **⌨️ Keyboard Shortcuts**:
  - Numbers `0-9`, decimal point `.`
  - Standard arithmetic operators `+`, `-`, `*`, `/`
  - Parentheses `(`, `)`
  - Backspace (Delete), Escape (Clear / AC), Enter or `=` (Compute)
- **📱 100% Fully Responsive**:
  - Adapts to mobile phones, tablets, and desktop widescreen displays.

## 🚀 Live Demo / Setup

No build steps required! Simply clone and launch:

```bash
# Clone the repository
git clone https://github.com/your-username/calculator.git

# Navigate to project folder
cd calculator

# Open index.html in your default browser
start index.html
```
